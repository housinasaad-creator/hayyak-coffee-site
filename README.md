# Hayyak · حيّاك

Concept demo website for a fictional Arabic & Syrian coffee roaster (wholesale only), in Arabic, Turkish and English.

- Scroll-driven real-time 3D journey (cardamom pod, roasting bean, grinding, the cup, the pour) built with three.js, ending with an interactive hospitality ritual: *the coffee never ends until you shake the cup*.
- Pages: home, products, the world of coffee (etiquette, roast scale, brew calculator, a turn-the-cup game), about.
- All geometry, textures and sounds are generated in code; fonts and three.js are bundled locally.
- The brand, products and contact details are fictional and for illustration only.

Designed & built by [MOHAMMED Web Studio](https://housinasaad-creator.github.io/mohammed-studio/).
